## 三、运行（在 VS Code 里完成）
1. 左侧资源管理器展开 `unit00_env`，右键 → 新建文件 → `hello.py`，写完按 **`Ctrl+S` 保存**
2. 在内置终端里：
   ```powershell
   cd E:\python\unit00_env
   python hello.py
   ```
3. 确认输出与预期一致

**两个 VS Code 特有的坑：**
- **不保存 = 跑的是旧代码**。VS Code 默认不自动保存，改完必须 `Ctrl+S`，否则解释器读到的还是磁盘上的旧内容，你会以为"改了没用"。
- **点 ▷ 可以，但要看它做了什么**。终端里会打印它执行的命令（带完整路径），读一眼；同时自己用 `cd unit00_env` + `python hello.py` 再跑一次。注意两种方式的工作目录不同：▷ 从项目根 `E:\python` 启动，U1 读相对路径的 CSV 时这个差别会真的坑你。F5 是调试器，U2 再学。
