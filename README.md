# Python 运维自动化学习

面向零基础运维人员，以 Windows、网络和日常运维场景为背景，逐步学习编写可靠、可维护的自动化工具。Python 是高级运维能力的一部分，还需要结合系统、网络、安全和故障排查知识。

## 学习进度

- 当前阶段：第一阶段，编程基础。
- 当前单元：运行程序与变量入门。
- 已讲解：运行 Python 文件、`print`、简单计算和变量赋值（以交换机端口为例）。
- 练习状态：已布置将总端口改为 48、已用端口改为 15 的练习；尚未收到运行结果，未确认完成。

学习过程中在这里更新单元、完成情况、获得的帮助和需要复习的内容；看过讲解或示例不等于独立完成。

## 第一阶段：编程基础

目标：看到简单需求，能自己想清楚步骤并写出代码。

| 单元 | 学习内容 | 运维练习 |
| --- | --- | --- |
| 1. 运行程序 | 文件、终端、`print` 和简单计算 | 计算空闲端口 |
| 2. 变量和数据 | 变量、数字、字符串 | 保存设备名和端口数量 |
| 3. 条件判断 | 比较、`if/else` | 判断磁盘空间是否不足 |
| 4. 列表 | 保存和读取多个值 | 管理一组设备名称 |
| 5. 循环 | 对多条数据重复操作 | 逐台显示设备名称 |
| 6. 字典 | 用字段描述一条记录 | 保存设备名称、IP 和状态 |
| 7. 组合处理 | 列表、字典、循环和条件组合 | 找出离线设备 |
| 8. 函数 | 整理可重复使用的功能 | 对多台设备使用同一判断规则 |
| 9. 基础排错 | 阅读报错、定位代码、处理常见异常 | 处理错误的端口数量输入 |

阶段作品：使用虚构数据制作设备状态统计程序，不连接设备。

## 第二阶段：文件和数据

目标：让程序读取和输出文件，处理日常台账和报告。

| 单元 | 学习内容 | 运维练习 |
| --- | --- | --- |
| 1. 路径与文本 | 文件路径、读取和写入文本 | 读取设备名称清单 |
| 2. CSV | 表格数据的读取与写入 | 处理设备资产台账 |
| 3. JSON | 结构化数据 | 读取设备配置样本 |
| 4. 数据清洗 | 缺失值、重复项、格式不一致 | 检查资产表中的问题 |
| 5. Excel | 工作簿、工作表、单元格 | 生成设备统计表 |
| 6. 报告生成 | 汇总数据和输出结果 | 生成巡检摘要 |

阶段作品：资产清单整理工具，读取样本台账、检查数据、统计设备并导出结果。

## 第三阶段：系统与网络

目标：从处理静态数据，走到采集本机和测试网络的信息。

| 单元 | 学习内容 | 运维练习 |
| --- | --- | --- |
| 1. Python 环境 | 虚拟环境、安装和管理依赖 | 建立独立的项目环境 |
| 2. 本机信息 | 系统、磁盘、内存等 | 生成本机基本信息报告 |
| 3. 系统命令 | 运行命令、读取输出和退出状态 | 检查测试环境中的服务状态 |
| 4. 网络基础应用 | DNS、IP、端口与连接超时 | 检查测试地址的端口 |
| 5. 日志 | 记录时间、结果和错误 | 保存巡检过程 |
| 6. 定时运行 | Windows 任务计划程序 | 定时执行本机巡检 |
| 7. 多目标处理 | 顺序检查，再按需学习并发 | 检查多台测试设备 |

阶段作品：只读巡检工具，收集本机信息或检查测试设备，生成结果与日志。

## 第四阶段：API 与自动化

目标：让程序获取不同系统的数据，并把它们组织起来。

| 单元 | 学习内容 | 运维练习 |
| --- | --- | --- |
| 1. HTTP 基础 | 请求、响应、状态码 | 请求测试接口 |
| 2. 解析 JSON | 读取接口返回的数据 | 获取设备名称和状态 |
| 3. 接口认证 | 令牌及凭据的基本管理 | 安全调用测试接口 |
| 4. 异常处理 | 超时、失败、错误信息 | 区分接口故障和数据问题 |
| 5. 分页与重试 | 获取多页数据、控制重试 | 读取较多设备记录 |
| 6. 数据比对 | 不同来源的数据匹配 | 比对接口数据和资产台账 |
| 7. 写入操作 | 请求修改、权限、预览和确认 | 在测试环境修改测试记录 |

阶段作品：资产信息比对工具，从测试接口获取数据，与本地台账比较，输出差异报告。

## 第五阶段：工程化

目标：把能运行的脚本整理成可靠、可维护、可以交给别人使用的工具。

| 单元 | 学习内容 | 运维练习 |
| --- | --- | --- |
| 1. 整理代码 | 拆分模块、明确职责 | 把巡检工具拆成采集和报告部分 |
| 2. 参数和配置 | 命令行参数、配置文件 | 运行时指定设备清单 |
| 3. 测试 | 自动验证结果 | 测试正常、空数据和失败场景 |
| 4. Git | 记录变更、分支和回退 | 管理自己的工具项目 |
| 5. 安全和可靠性 | 凭据、最小权限、重复执行 | 检查工具的操作边界 |
| 6. 交付 | 使用说明、依赖、运行步骤 | 让另一位同事按说明运行 |

阶段作品：将巡检或资产工具整理成完整项目，包含代码、配置示例、测试和使用说明。

## 学习方式

围绕逐步成长的运维工具学习：解释问题、演示、亲手修改、完成相近练习，再检查和复盘。每一步根据实际练习结果推进，有基础的部分可以加快，卡住时拆小，不按固定天数赶进度。

练习使用虚构数据或测试环境，先只读再考虑修改操作。Windows 运维可按工作需要配合学习 PowerShell。
